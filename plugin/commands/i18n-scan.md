description: "Scan your codebase for hardcoded strings that should be internationalized. Shows priority scores and suggests semantic keys."
argument-hint: "[path] e.g. src/components"
---

Run the **SCAN** workflow from the smart-i18n skill. Find all hardcoded, user-facing strings in the codebase using the heuristic scoring system. Group results by file with priority indicators and suggest semantic key names.

If the user provided a path argument, scan only that directory/file. Otherwise, scan the entire project.
